# Nexora VPE — Virtual Patient Engine

Nexora VPE هو أساس منصة محاكاة تعليمية لمرضى افتراضيين. يركز نطاق **S0** الحالي على حالة واحدة فقط: إصابة بطنية لدى بالغ مع تمزق طحال ونزف داخلي متفاقم وصدمة نزفية. المنتج في هذه المرحلة للتعلّم التكويني فقط، وليس لاتخاذ قرار علاجي حقيقي أو لتقييم عالي العواقب.

> **مبدأ معماري:** الحالة الفيزيولوجية والحقائق السريرية مصدرها محرك محاكاة وحالة سيناريو مرجعية؛ طبقات الذكاء الاصطناعي تعبّر عن الحقائق المسموح بها فقط ولا تغيّرها.

## الحالة الحالية

المستودع بدأ كتأسيس قابل للمراجعة. تدقيق المستودع موثق في [تقرير التدقيق](docs/reports/001-repository-audit.md)، وحالة العمل المحدثة في [CURRENT_STATUS](docs/status/CURRENT_STATUS.md). لم تُنفّذ بعد تجربة Pulse محليًا؛ لذلك لا توجد ادعاءات بخصوص صلاحية Pulse أو Unity أو قابلية إعادة التشغيل.

## المعمارية المستهدفة

```text
أفعال المتعلم المنظمة
        ↓
نواة VPE (ساعة المحاكاة، الأوامر، السيناريو، الملاحظات، الأدلة)
        ↓
واجهة تكييف الفيزيولوجيا (Pulse مرشح رهن Gate A)
        ↓
حالة المريض المرجعية
        ↓
ملاحظات متاحة للمتعلم ← واجهة عميل / تعبير لغوي غير مرجعي
```

لا يتقدم الزمن السريري إلا عبر مالك واحد لساعة المحاكاة داخل VPE. لا تملك واجهة Unity أو موفر لغوي حق تغيير الفيزيولوجيا مباشرة.

## البدء والتكرار

لا توجد متطلبات تشغيلية أو حزمة تنفيذ مستقرة حتى الآن. سيكون تسلسل العمل القابل للتكرار، بعد إضافته، كما يأتي:

```text
clone → تثبيت المتطلبات → تشغيل الاختبارات → تشغيل تجربة Gate A → فحص النتائج الممثلة
```
