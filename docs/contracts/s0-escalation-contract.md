# عقد التصعيد المنظم في S0

## الغرض

يوثق هذا العقد فعلاً سريريًا **منظمًا ومصرحًا به في السيناريو** لأغراض التعلم وإعادة العرض والتغذية الراجعة التكوينية. لا يغيّر التصعيد حالة Pulse، ولا يحرّك ساعة المحاكاة، ولا يرسل أمرًا إلى خدمة خارجية، ولا يثبت أن الفعل مناسب لمريض حقيقي.

> **التصعيد هنا دليل على اختيار متعلم داخل حالة محاكاة S0 فقط، وليس توصية علاجية أو قرار قبول/نقل أو تقييم أداء عالي العواقب.**

## مصدر السلطة

يعرّف مؤلف السيناريو الخيارات ضمن `escalations.allowed`. النواة لا تقبل نصًا حرًا أو اسم جهة أو قرارًا غير موجود في هذا القاموس. يمثل المعرف قيمة ثابتة قابلة للمراجعة، بينما يبقى تفسيره المستقبلي للتغذية الراجعة محكومًا بالسياق واللقطات المسجلة، لا بالاسم وحده.

```json
{
  "escalations": {
    "allowed": [
      {"id": "trauma_team_escalation"}
    ]
  }
}
```

| الحقل | القيد | السبب |
|---|---|---|
| `id` | سلسلة غير فارغة ومطابقة لمفتاح القاموس | يمنع التعريفات الملتبسة. |
| `escalation_id` في الأمر | سلسلة تطابق عنصرًا في `escalations.allowed` | يمنع الأفعال الحرة وغير المراجعة. |
| `actor` | يمر عبر envelope القائم لـ VPE | يحافظ على النسبة والتسلسل. |
| وقت الحدث | زمن VPE الحالي فقط | لا يضم زمن واجهة أو شبكة أو نموذج لغوي. |

## مسار التنفيذ

```text
Client / future Unity
        ↓  CommandKind.RECORD_ESCALATION
VpeRuntime command queue
        ↓  validate escalation_id against scenario
EventType.ESCALATION_RECORDED
        ↓
Evidence store / replay / formative debrief
```

لا توجد في هذا المسار مكالمة إلى `PhysiologyAdapter` أو `PulseAdapter`، ولذلك لا ينشر لقطة جديدة ولا يغير telemetry أو زمن المحاكاة.

## عقد الحدث

بعد قبول الأمر، ينشر `VpeRuntime` حدثًا واحدًا فقط بهذه الخصائص الثابتة:

| الحقل | القيمة |
|---|---|
| `event_type` | `escalation.recorded` |
| `source` | `scenario_runtime` |
| `payload.command_id` | معرف الأمر المرتب من VPE |
| `payload.escalation_id` | معرف الخيار الموافق عليه في السيناريو |
| `simulation_time_s` | زمن VPE عند معالجة الأمر |

يرفض runtime معرفًا مفقودًا أو غير نصي أو غير موجود في سيناريو S0 بـ`ValueError`. الرفض لا ينشر حدثًا بديلًا ولا يستدعي Pulse.

## نطاق التحقق

اختبارات النواة تثبت قبول `trauma_team_escalation` ونشر الحدث بالشكل المذكور، وعدم تغيير الزمن أو عدد اللقطات، ورفض معرف غير معتمد. حزمة الاختبار الكاملة تشغّل أيضًا اختبارات PulseAdapter الفعلية لتثبت أن إضافة هذا المسار غير الفيزيولوجي لم تكسر عقد التكامل القائم.

لا تثبت هذه الاختبارات صحة طبية أو تعليمية مستقلة، ولا تدّعي أن الترتيب أو التوقيت أو محتوى التصعيد يكفي لاتخاذ قرار في واقع سريري.
