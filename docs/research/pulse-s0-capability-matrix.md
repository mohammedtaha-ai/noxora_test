# مصفوفة قدرات Pulse لحالة S0 — قبل تنفيذ Gate A

**تاريخ الوصول:** 2026-08-22
**الحالة:** **PRE-EXPERIMENT** — هذه ليست مخرجات Gate A ولا يجوز قراءتها كتصديق محلي.
**المرجع التفصيلي:** [مراجعة Pulse التقنية](pulse-technical-review.md).

> تُستخدم حالات `SUPPORTED` و`PARTIAL` و`ABSENT` في حكم Gate A النهائي فقط حين يكون لكل صف دليل تنفيذ محلي. قبل ذلك، تستخدم هذه الوثيقة حالة بحث أكثر تحفظًا: `UPSTREAM DOCUMENTED` أو `UNTESTED` أو `PARTIAL`.

## ملخص القرار المؤقت

| شرط Gate A الحاسم | وضعه قبل التجربة | المبرر |
| --- | --- | --- |
| تقدم زمن تتحكم به VPE | **UPSTREAM DOCUMENTED** | واجهة Pulse توثق أن التطبيق يتقدم بالزمن؛ لم يثبت بعد التسلسل المختار محليًا. [1] |
| مسار نزف مناسب | **PARTIAL** | فعل النزف ومخرجات الفقد موثقة؛ النزف الداخلي/الطحالي المحدد غير مثبت. [2] [3] |
| مخرجات مراقبة أساسية | **UPSTREAM DOCUMENTED** | توجد أدلة منهجية/إصدار على HR وBP/MAP وحجم/فقد الدم؛ أسماء الطلبات الفعلية لا تزال غير ملتقطة. [2] [3] |
| إنعاش أساسي | **UNTESTED** | توجد واجهات إعطاء مواد، لكن البلورانيات وPRBC لم تشغّل. [4] |
| حفظ/تحميل | **UPSTREAM DOCUMENTED** | الواجهة توثق حفظ/تحميل الحالة؛ تكافؤ المسار اللاحق غير مختبر. [4] |
| تشغيل رأسي مستقر | **UNTESTED** | لا يوجد بناء أو عملية محلية ناجحة حتى الآن. |

## معايير التحويل إلى حكم Gate A

لكل صف حاسم، يجب أن تضيف التجربة رابطًا إلى: أمر التشغيل، hash مصدر Pulse، تهيئة المريض، زمن المحاكاة، سجل، CSV/JSON صغير، واختبار آلي أو مقارنة نتائج. عندها فقط يكون الحكم أحد:

| الحكم النهائي | المعنى |
| --- | --- |
| **SUPPORTED** | نفذت القدرة على المرجع المثبت وأعطت السلوك/المخرج المطلوب ضمن حدود التجربة. |
| **PARTIAL** | توجد قدرة قابلة للاستخدام لكن مع قيد واضح أو تحول أو حل بديل محدود موثق. |
| **ABSENT** | لم توجد القدرة أو أخفقت التجربة، ولا يوجد حل ضمن ميزانية S0. |
