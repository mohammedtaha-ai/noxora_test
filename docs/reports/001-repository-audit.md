## توصية سير العمل

التوصية هي العمل على فرع `manus/s0-foundation`، لأنه لا توجد سياسة فروع موروثة ولا يوجد فرع افتراضي قابل للاستخدام. سيصبح هذا الفرع أساسًا قابلاً للمراجعة لتدقيق المستودع، أبحاث Gate A، والتجارب الصغيرة. لا يُنفذ تطوير غير مضبوط على `main`.

سيكون التسلسل التالي:

```text
تدقيق المستودع
  → التزام ودفع التأسيس
  → بحث Pulse + بروتوكول Gate 0
  → التزام ودفع البحث
  → تجربة Pulse رأسية فعلية (Gate A)
  → تقرير أدلة/ADR للطوبولوجيا
  → تصميم S0 ثم نواة VPE الرأسية
```
