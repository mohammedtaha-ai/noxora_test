## فحص قواعد القرار

| قاعدة البروتوكول | الدليل المتاح | النتيجة |
|---|---|---|
| عينة ≥5 متعلمين و≥3 مدرّسين/مثقفين |  | MET / NOT_MET |
| أغلب المشاركين يصفون قيمة تتجاوز الجدة |  | MET / NOT_MET / UNCLEAR |
| اثنان على الأقل من ثلاثة مدرّسين راغبون بتجربة مشروطة |  | MET / NOT_MET / UNCLEAR |
| لا يطغى عائق سير عمل غير معالج |  | MET / NOT_MET / UNCLEAR |
| لم تظهر قاعدة STOP/PIVOT |  | MET / NOT_MET / UNCLEAR |

## القرار

اختر **واحدًا فقط** بعد ملء الأقسام السابقة:

- `PASS (اتجاهي)`: تتوافر شروط البروتوكول، مع توثيق ما لا تزال لا تثبته البوابة.
- `PIVOT / REWORK`: تحقق معيار STOP أو عائق غالب، مع صاحب الإجراء وتاريخ المراجعة.
- `INCONCLUSIVE`: لم تكتمل العينة أو لم يتوافر دليل صالح؛ لا يحول النقص إلى حكم قيمة.
