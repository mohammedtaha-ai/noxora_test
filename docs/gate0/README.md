# حزمة تنفيذ Gate 0

**الحالة:** `READY_FOR_EXECUTION / UNTESTED`. هذه الحزمة تحول بروتوكول Gate 0 إلى مواد تشغيلية، لكنها لا توثق جلسات فعلية ولا اجتيازًا للبوابة.

> الغرض هو اختبار قيمة تعليمية محسوسة مرتبطة بعواقب متغيرة وإعادة مراجعة في مفهوم Wizard-of-Oz. ليست الحزمة دراسة فعالية، مراجعة طبية، أو تقييم أداء؛ ولا تستخدم Pulse أو Unity أو LLM أو بيانات مرضى حقيقية.

## شروط البدء

لا تبدأ جلسة إلا بعد تعيين ميسر، اعتماد نص المؤسسة للمعلومات/الموافقة، تأكيد عدم جمع أي بيانات مريض أو هوية غير لازمة، وتخصيص معرف مشارك مجهول. إذا تطلب سياق المؤسسة مراجعة أخلاقية أو IRB، تُستكمل الموافقة المحلية أولًا. لا يفسر عدم إكمال العينة كـPASS أو PIVOT؛ النتيجة عندئذ `INCONCLUSIVE`.

## المخرجات المسموح بها

تنتج كل جلسة صفًا مجهولًا في ورقة التقاط الدليل وملاحظات ميسر مختصرة. لا تُحوّل التفاعلات إلى درجات سريرية، ولا تُجمع كمقياس فعالية إحصائي، ولا يُدعى أن أي استجابة تمثل سلوكًا علاجيًا صحيحًا.

## حماية النطاق

تستخدم النسخة B نصوصًا أو شرائح معدة مسبقًا فقط. لا تستبدل هذه الحزمة Gate 0 بواجهة Unity أو محرك Pulse أو FAST مكاني. لا تبدأ Unity نتيجة تجهيز هذه المستندات.
